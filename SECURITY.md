## Reporting a Vulnerability

We take the security of this project and the environments it operates on seriously.

If you discover a security vulnerability or potential risk within any template or script:

1. **Do not open a public issue.**
2. Report the vulnerability privately through [GitHub Security Advisories](https://github.com/h4rysh/github-repo-architect/security/advisories/new).
3. Alternatively, email the maintainer directly at `harrishgayathri@gmail.com`.

### Response SLA
- **Initial Response**: Within 24-48 hours with confirmation of receipt.
- **Triage & Remediation**: Within 7 business days for verified critical/high issues.
- **Public Disclosure**: Coordinated following the release of an update or patch.
